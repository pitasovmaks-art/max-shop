# Точка Монтажа — статус проекта

Мини-приложение для Max Messenger. Магазин строительных инструментов с каталогом, корзиной и оформлением заказа.

---

## Стек

- **Frontend**: Vanilla JS, HTML/CSS (без фреймворков)
- **Backend**: Node.js + Express
- **БД**: PostgreSQL — Brainy Aquila, хост `192.168.0.5` (Timeweb внутренняя сеть), SSL `rejectUnauthorized: false`
- **S3**: Timeweb, бакет `tochka-montazha-images`, endpoint `s3.twcstorage.ru`
- **Деплой**: Timeweb App Platform
- **Продакшен URL**: `https://pitasovmaks-art-max-shop-c149.twc1.net`
- **Платформа**: Max Messenger Mini App SDK (`https://st.max.ru/js/max-web-app.js`)

## Архитектура выбора города

Пользователь выбирает один из двух городов при входе — **Краснодар** или **Москва**. Выбор хранится в `localStorage('city')` как код (`krd` / `msk`). TTL — **15 минут** (900 000 мс, `cityTimestamp`).

- `krd` → цены `price_krd` (вариант: `variant.priceKrd`)
- `msk` → цены `price_msk` (вариант: `variant.priceMsk`)
- Если TTL истёк — экран выбора города показывается снова, каталог не загружается

Кнопка города в хедере (`📍 Краснодар` / `📍 Москва`) позволяет сменить город.

## Способы получения заказа

В `checkout.html` три вкладки:

| Способ | Код | Цена | Что показывается |
|---|---|---|---|
| 🏪 Самовывоз | `pickup` | city-цена | Список магазинов (отфильтрован по городу) |
| 🚗 По городу | `city` | city-цена | Поле «Адрес доставки» |
| 📦 По России | `russia` | `price_delivery` | Поле «Адрес доставки» |

При смене способа пересчитывается итоговая сумма заказа.

## Маршрутизация уведомлений бота

- **Самовывоз** → по имени выбранного магазина (`STORE_MANAGERS` в `bot.js`)
  - `Краснодар, ул. Селезнева` → `315827109`
  - `Краснодар, ул. Котлярова` → `403249437`
  - `Москва, Аллея Первой Маевки` → `392912448`
- **Доставка по городу / по России** → по коду города (`CITY_MANAGERS` в `bot.js`)

  - `msk` → `392912448`
- Если менеджер не найден — уведомление уходит всем известным менеджерам

## Бот Max Messenger (`bot.js`)

- **Режим: webhook** (переключён с long polling 26 мая 2026)
- `API_BASE = 'platform-api.max.ru'` — без префикса `/v1/`
- При старте сервера: `registerWebhook()` → `POST https://platform-api.max.ru/subscriptions`
- Endpoint для приёма обновлений: `POST /webhook` в `server/index.js`
- Список admin chat_id хранится в `bot_admins.json` (каждый кто нажал /start — становится админом)

**Команды:**
- `/start` / `bot_started` — приветствие + кнопка «🛒 Открыть магазин»
- `/myid` — отвечает своим chat_id
- `/reply ID текст` — только для админов, отправляет ответ пользователю
- Любое сообщение от не-админа — автоответ + пересылка всем админам с инструкцией `/reply`

## Реализовано

### Каталог (`index.html`, `src/catalog/`)
- Экран выбора города: 2 большие кнопки «Краснодар» / «Москва», TTL 15 мин
- Кнопка города в хедере (смена города)
- Загрузка товаров, категорий и подкатегорий из API
- Фильтрация по категории и подкатегории
- Поиск с debounce 250 мс
- Двухколоночная сетка карточек (glassmorphism)
- Бейджи «Нет в наличии» и бренд на фото
- Варианты товара (пилюли) с выбором и обновлением цены
- Городские цены в карточках (`price_krd` / `price_msk`)
- Клик на карточку → страница товара

### Страница товара (`src/catalog/product.html` + `product.js` + `product.css`)
- Загрузка товара и дополнительных фото из API
- Свайп-галерея с touch-событиями
- Две стрелки навигации (prev/next), скрываются на крайних фото
- Точки-индикаторы под галереей
- Стрип миниатюр (thumbnail strip)
- Варианты товара с выбором цены
- Городские цены (`price_krd` / `price_msk`)
- `priceDelivery` сохраняется в элемент корзины при добавлении
- Кнопка «В корзину» / «Записаться» / «Нет в наличии»

### Корзина (`cart.html`, `src/cart/cart.js`)
- Список товаров с количеством и итоговой суммой
- Изменение количества и удаление позиций
- Бейджи с количеством в хедере и навбаре
- Хранение в `localStorage`

### Оформление заказа (`checkout.html`, `src/cart/checkout.js`)
- Три способа получения: Самовывоз / По городу / По России
- Список магазинов отфильтрован по городу пользователя
- Поле адреса для доставки по городу и по России
- Пересчёт суммы при смене способа (Russia → `priceDelivery`)
- Форма: имя, телефон (маска), комментарий
- Согласие с офертой (чекбокс)
- Экран успеха с иконкой/подписью по способу получения

### Бот и уведомления
- Уведомление менеджеру при каждом новом заказе
- Маршрутизация: самовывоз → по магазину, доставка → по коду города
- Формат уведомления содержит способ, магазин или адрес

### Backend API (`server/`)
- `GET /api/config` — `{ botUsername }` для фронтенда
- `POST /webhook` — принимает обновления Max Bot API
- `GET/POST/PUT/DELETE /api/products` (с `price_krd`, `price_msk`, `price_delivery`, вариантами, фото)
- `GET/POST/PUT/DELETE /api/categories`, `/api/subcategories`
- `GET/POST/PUT /api/orders` (с полями `delivery`, `address`, `city`)
- `GET/POST/PUT/DELETE /api/stores`
- `POST /api/upload` — загрузка файла в S3, возвращает URL
- `POST /api/auth/login` — выдача JWT
- `POST /api/admin/reset` / `/api/admin/seed` — сброс и заполнение БД

### БД (`server/db.js`)
- Таблицы: `products`, `categories`, `subcategories`, `product_variants`, `product_images`, `orders`, `stores`
- Авто-создание схемы (`CREATE TABLE IF NOT EXISTS`) + безопасные миграции (`ALTER TABLE ... ADD COLUMN IF NOT EXISTS`)
- Авто-сид при пустой базе
- `orders` содержит поля: `delivery`, `address`, `city` (добавлены как nullable/default)

### Админ-панель (`admin/`)
- Авторизация: пароль `1608`, JWT, сессия **60 минут** (ключи `adminAuth` + `adminAuthTime` в `localStorage`)
- CRUD товаров: поля цен `price`, `price_krd`, `price_msk`, **`price_delivery`**
- Варианты товара: те же 4 поля цен на каждый вариант
- Загрузка фото в S3 (основное + дополнительные)
- CRUD категорий и подкатегорий
- Просмотр и управление заказами (статусы: new / processing / done / cancelled)
- Управление магазинами (stores)
- Статистика: всего / в наличии / нет в наличии

## Нерешённые задачи и известные проблемы

- **Существующие корзины**: у пользователей, добавивших товары до Task 8, в `localStorage` нет поля `priceDelivery` — при выборе «По России» будет `0`. Решение: при первом открытии checkout обнулять корзину или мигрировать цены через повторный fetch.
- **Webhook регистрация**: после деплоя проверить лог `[bot] Webhook зарегистрирован, статус: 200`.
- **Кнопка «Поддержка»**: ссылка `https://max.ru/<username>` — проверить работу внутри Mini App iframe.
- **Котлярова (403249437)**: менеджер добавлен в `STORE_MANAGERS` но не в `CITY_MANAGERS` — если доставка из Краснодара, уведомление уходит на Селезнева (315827109). Уточнить, верно ли это.
- **Перебой выбора варианта в каталоге**: при добавлении в корзину из каталога использовалась `variant.price` вместо `getEffectivePrice(product, variant)` — исправлено в Task 8, но старые записи в корзине могут содержать некорректную цену.
